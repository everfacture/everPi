How to Evaluate Success

  1. Repo exists: open https://github.com/everfacture/everpi — should show 18+ files, clean structure
  2. Installable: On a fresh machine: pi install git:github.com/everfacture/everpi
  3. Extension loads: After /reload, /evaluation-mode should toggle without args
  4. No personal data: No hardcoded API keys, no /Users/ibby paths in committed files
  5. Attribution present: everpi-yolo README credits @gotgenes; protected-sensitive-files credits Pi examples

Known Limitations

  • Evaluation mode is not enforced — it appends text to the system prompt. The LLM may ignore it. No hard gate.
  • TinyFish skill — the binary and SKILL.md are included but this is community software, not authored by the repo owner. Should be curated, not claimed.
  • everpi-yolo — is a thin wrapper around @gotgenes/pi-permission-system. Not much original code; mostly config.
  • No tests — extensions are not tested in isolation before pushing.
  • Dependencies — @gotgenes/pi-permission-system requires npm install after pi install. This step is documented but easy to miss.

Not Verified

  • Clean install on a fresh machine — has not been tested end-to-end
  • everpi-yolo behavior with the packaged config.json (tested locally but not via pi install)
  • Prompt template expansion with ${ARGUMENTS:+: $@} — syntax is correct but not tested in a live Pi session
